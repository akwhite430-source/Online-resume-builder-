# Online Resume Builder

A responsive resume builder made with HTML, CSS, and JavaScript.

## Features
- Enter personal and professional details
- Live resume preview
- Three templates: Modern Blue, Professional Green, and Classic Black
- Save and load details using browser Local Storage
- Print the resume or choose **Save as PDF** in the browser print dialog
- Responsive layout for mobile and desktop

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in Google Chrome or another modern browser.
3. Enter details and use the buttons to generate, save, load, or print the resume.

## Files
- `index.html` — page structure
- `style.css` — layout and styling
- `script.js` — preview, template, save/load, and print functions

Note: Saved details stay in the same browser on the same device. This demo does not upload personal information to a server.
